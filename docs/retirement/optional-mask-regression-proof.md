## Narrow short-budget correction and retained debt

Source review found that the original 80 ms schedule was not equivalent before this correction. `pixel_lease` reserves one fifth of the remaining parent budget, capped at 500 ms. With an 80 ms parent, its reserve is at most 16 ms. `retained_read_command` previously waited up to 250 ms after interruption even for a non-resource, non-mutating `DOMSnapshot.captureSnapshot` read. A reply held until after terminal completion therefore consumed the parent budget before optional omission could publish.

The approved correction matches only the exact `DOMSnapshot.captureSnapshot` method after interruption. This protocol response contains value data, not remote handles, and does not mutate the page. Cancellation is checked first; otherwise the original interruption reason is retained. Dropping the local waiter allows acknowledged restoration and optional publication inside the original parent budget. All other methods, including `Runtime.evaluate`, resource-producing reads, unknown commands, and mutations, retain their existing conservative settlement. No prefix-based or general read exemption was introduced. The caller still applies scope, geometry, privacy and cleanup checks.

Transport ownership is unchanged. Dropping a receiver is not settlement of the remote operation. `interrupted_value_only_mask_snapshot_retains_exact_debt_until_late_reply` separately installs a real `OwnerDebtLedger` and operation journal, exercises both deadline and cancellation with an 80 ms parent, and requires one outstanding command with zero object/input debt after the waiter has detached. Only the matching late response settles that command. The test requires zero outstanding commands afterward, no integrity loss, and no follow-on application or cleanup command. The full dispatcher fixture does not itself install a ledger; its `pending_len` assertion alone is not offered as debt proof.

The 80 ms tests use real `std::time::Instant`, not a synthetic clock. Exact runtime behavior and scheduling stability on the actual CI runner are unverified. No test was relaxed to a longer budget to conceal the original boundary.
