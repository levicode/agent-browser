# Upstream relationships and patch retirement

Reviewed against official commit `5ee8691339a5a002e4d7454eec95250253bc7419`. Issue/PR status is a review-time observation, not a permanent assertion or evidence that community patches passed our tests. Recheck at each upgrade.

| Area | Official work and design consequence | Retirement proof |
| --- | --- | --- |
| Ref identity | [#1812](https://github.com/vercel-labs/agent-browser/pull/1812) binds identity to session/document/frame/backend node. Reuse upstream `add_exact_backend_node` rather than a second identity engine. [#806](https://github.com/vercel-labs/agent-browser/pull/806) deliberately retained role fallback; exact no-fallback references are an explicit caller contract, not a claim all fallback is a bug. | Same-document, document replacement, renderer/session replacement, stale-node and duplicate-name tests. |
| Lost mutation response | [#2085](https://github.com/vercel-labs/agent-browser/pull/2085) stops transport resend and reports `outcome_unknown`. Preserve that outcome; `dispatched:false` is only a proven pre-input rejection, not permission to replay ambiguous failures. | Response loss across CLI/daemon/adapter/runner; external side-effect oracle. |
| Fill | [#2069](https://github.com/vercel-labs/agent-browser/pull/2069) discusses narrowly supported value-type setters. Do not replace ordinary text or rich-editor input with blanket synthetic DOM writes. | Text, textarea, supported value types, contenteditable and framework-controlled fields; event trust/focus expectations stated explicitly. |
| Selection | [#1736](https://github.com/vercel-labs/agent-browser/pull/1736) normalizes ordinary selection matching. Keep auto semantics on shared matcher; explicit value/label/index arguments identify intent. | Whitespace normalization, duplicate labels/values, disabled options, single/multiple selection. |
| Passive attachment | [#1589](https://github.com/vercel-labs/agent-browser/pull/1589) pins a tab but does not by itself establish immutable context or a single Fetch/pause owner. [#2110](https://github.com/vercel-labs/agent-browser/pull/2110) adds lossless method taps; never regress to a lag-dropping transport during merges. | Popup/OOPIF first request, no foreign-session touch, no native Fetch/auth response or debugger resume, context revocation and teardown. |
| Lifecycle races | [#1893](https://github.com/vercel-labs/agent-browser/pull/1893), [#1923](https://github.com/vercel-labs/agent-browser/pull/1923), [#1992](https://github.com/vercel-labs/agent-browser/pull/1992) discuss reconnect, navigation and detached sessions. Target, CDP session and document lifetimes are different. | Independent invalidation by each lifetime and no stale pending command hang. |
| Pointer limitations | [#2083](https://github.com/vercel-labs/agent-browser/issues/2083), [#2146](https://github.com/vercel-labs/agent-browser/issues/2146) expose scrolling/background-target delivery concerns. Exact refs do not make coordinate dispatch atomic. | Actual hit/effect assertions under moving overlay and background-target conditions, not only CDP acknowledgments. |

The fork does not automatically adopt open PRs or promise future acceptance. Each downstream family needs an owner, contract tests and a deletion condition. A textual merge, similarly named flag or lower diff count is insufficient to remove a boundary. No upstream issues or PR comments are posted automatically.
